# ZenithGDPS
### Open source private server for Geometry Dash written in JavaScript    

Supported versions of Geometry Dash
```
- Lite 1.01_1
```

Required version of Node.js: v26.10.0+

---

# Setup
1. Download the repository by zip or type this into the Terminal: `git clone https://github.com/astralsc/ZenithGDPS.git`
2. Go into Command Prompt or Terminal and type `npm install` to build the server.
3. Go into Command Prompt or Terminal and type `node .` to start the server.
